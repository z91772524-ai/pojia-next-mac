# Binary Analysis

Hash and identify the artifact, map headers and sections, extract strings and
imports, then locate decisive control flow. Route to `objdump`, `radare2`,
`ghidra`, `jadx`, `apktool`, `dnspy`, or `frida` as the format requires. Keep
addresses, offsets, hashes, and runtime observations in the findings ledger.
