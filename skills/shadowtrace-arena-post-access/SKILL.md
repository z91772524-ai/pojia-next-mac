# Post-Access Analysis

Snapshot identity, privileges, services, scheduled work, startup locations, and
network relationships. Test one boundary hypothesis at a time and preserve state
deltas. Route Windows relationship collection through `bloodhound` and platform
queries through `powershell`, `reg_query`, or `wmic`.
