# ShadowTrace Reporting

Build the report from evidence, not from chronology.

## Required sections

1. Outcome and confidence.
2. Challenge surface and supplied artifacts.
3. Root cause or weak-point class.
4. Decisive evidence.
5. Minimal reproduction steps.
6. Solver or artifact paths.
7. Discarded paths that prevent duplicated work.

Redact unrelated credentials. Keep hashes, offsets, request fields, and command
arguments when they are required for reproduction.
