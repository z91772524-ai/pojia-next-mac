# Full Security Workflow

Initialize workspace state, map the surface, select the narrowest evidence-backed
path, and execute one variable at a time. Use capability tools through the chosen
backend. Continue through access and impact only when each checkpoint produces new
evidence, then build the report from the final reproducible chain.
