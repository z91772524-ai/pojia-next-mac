# Full Binary Workflow

Run artifact triage, binary analysis, anti-debug analysis, and protection analysis
in sequence. Recover the decision algorithm before making a compatibility change.
The completion gate is a clean-input reproduction with recorded hashes, offsets,
test vectors, and a reversible output artifact.
