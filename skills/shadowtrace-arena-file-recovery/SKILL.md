# File Recovery Lab

Work only on a disposable fixture copy. Define key generation, authenticated
encryption, extension selection, manifest format, and recovery order. Require a
dry run, per-file hashes, an untouched canary, and a decrypt-then-compare gate.
Document indicators that defenders can use to detect the transformation burst.
