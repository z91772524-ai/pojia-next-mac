# Network Assessment

Define target inventory and rate limits, then discover hosts and ports before
service-specific checks. Route through `nmap`, `masscan`, `tcpdump`, `netcat`,
`socat`, or `wireshark`. Preserve commands, timestamps, banners, packet captures,
and the smallest request that confirms each service finding.
