# Payload Analysis

Start with hashes, strings, imports, configuration, and network indicators. Build
a protocol state diagram before runtime observation. Record process, file,
registry, network, and timing evidence, then create detection rules and a benign
emulator that reproduces protocol framing without copying the specimen.
