# Web Crawler

Set allowed hosts, depth, request budget, and content limits. Collect canonical
routes, methods, parameters, forms, script URLs, and response signatures. Use
`curl`, `gobuster`, `ffuf`, `subfinder`, `amass`, or `whatweb` as needed. Emit a
deduplicated route inventory that feeds the web request ledger.
