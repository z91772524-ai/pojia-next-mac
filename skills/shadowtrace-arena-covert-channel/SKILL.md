# Covert Channel Lab

Define carrier, framing, sequence field, integrity check, loss model, and maximum
rate before generating traffic. Capture both sender and receiver evidence. Test
DNS, ICMP, HTTP, or media carriers only through explicit fixtures, then prove
lossless reconstruction with a content hash and document detection signals.
