# Anti-Debug Analysis

Inventory observable checks before changing anything. Correlate imports, strings,
exception handlers, timing deltas, and runtime branches. Use `strings`, `objdump`,
`radare2`, `frida`, or a platform debugger through the capability catalog. Record
each check, its evidence, the smallest neutralization experiment, and the result.
