# Code Transformation

Establish a behavioral baseline and retain a reversible transform manifest. Work
layer by layer: representation, strings, names, branches, then packaging. For
recovery, reverse that order and compare outputs against fixtures after every
stage. Never rely on visual similarity as proof of equivalence.
